Rename the Planet — a make.fun entry. One line under 200 characters that gives
a planet of our solar system a funny new name and says why in the same breath.

Our entry: **Mars is now "The Red Flag" — it keeps hinting it once had water,
then ghosts every rover we send to check.**

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This validates the line against the gate (1–200 characters counted per code
point, single line, not only whitespace, no leading/trailing space, valid
UTF-8) and writes it to `entry.txt` in the output directory.
